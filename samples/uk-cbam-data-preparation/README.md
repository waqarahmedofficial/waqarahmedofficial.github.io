# UK CBAM Data Preparation — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

A complete CBAM data-preparation worked example for a fictional UK importer (Harbour Steel Imports Ltd): scope mapping against the £50,000 threshold, and an embedded-emissions calculation for 3 iron & steel consignments with verified actuals vs HMRC default values side by side. Totals: 820.00 t imported; actual emissions 1,097.00 tCO2e vs 1,745.90 tCO2e on defaults; liability £10,197.68 on actuals vs £16,292.15 on defaults — a saving of £6,094.47 (37.4% of the default bill) from having supplier data. Also included: the 24-field supplier data-request template used to collect that data.

## Files in this folder

- `worked-example-dataset.csv` — the 3-consignment calculation dataset with totals
- `supplier-data-request-template.csv` — the 24-field supplier data request
- `method-and-sources.md` — the method, the UK rules relied on, and primary sources
- `validation-checks.txt` — the re-computation checks and their results

## Verification

Every figure was independently re-computed from its own inputs (mass × intensity × rate) and cross-checked against the totals row — **29/29 validation checks PASS** (see `validation-checks.txt`).
