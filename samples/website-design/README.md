# Website Design (Business Websites) — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

Three complete demo websites for fictional local trades businesses, each built as a single self-contained HTML file with services, trust signals, reviews and a contact/booking path: a plumbing company, a roofing company and an HVAC company — the standard of site offered to local businesses that have no website or an outdated one.

## Files in this folder

- `demo-plumbing.html` — Lone Star Plumbing Co., Plumber in Temple, TX (sample demo website)
- `demo-roofing.html` — Summit Ridge Roofing, Roofer in Killeen, TX (sample demo website)
- `demo-hvac.html` — Cool Breeze Air & Heat, HVAC Technician in Killeen, TX (sample demo website)

## Verification

Each demo is a complete, self-contained HTML file — it opens in any browser with no build step, server or external dependencies, and was checked page-by-page when built.

This is a sample built on fictional/practice data to demonstrate the service. Client work is delivered to the same standard.
