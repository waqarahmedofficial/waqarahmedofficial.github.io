# Amazon Flat-File Listings & Error Fixing — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

Two samples. Sample A (`sample-a-Template.csv`) is a completed Amazon flat file for the fictional brand "NorthPeak Home": a variation parent with its children plus standalone listings, every required field filled, together with `UploadNotes_Sample_A.txt` — the upload notes a client receives with a finished file. Sample B is the error-fixing side of the service: `sample-b-Upload Error Report (BEFORE).csv` carries real Amazon upload errors as they come back from Seller Central, and `sample-b-ChangeLog (AFTER).csv` shows every fix as SKU / field / old value → new value / reason. The service pack summary is `PACK.md`.

The original sample is an Excel workbook; each sheet is exported here as CSV so it can be viewed directly on GitHub.
