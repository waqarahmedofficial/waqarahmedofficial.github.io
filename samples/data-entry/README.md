# Data Entry — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

Sixty fictional business contacts converted from messy raw text — business-card and email-signature style, with ALL-CAPS names, "Last, First" orderings, honorifics, five different phone formats, abbreviated job titles and genuinely missing fields — into a clean, structured CSV with seven columns: First Name, Last Name, Company, Job Title, Email, Phone, City. Cleaning rules applied: honorifics removed, name order corrected, emails lowercased, phones normalised to (XXX) XXX-XXXX with extensions dropped, company suffixes standardised, title abbreviations expanded, and fields missing from the source left blank rather than invented (13 blanks in total: 5 Phone, 4 Job Title, 4 City).

## Files in this folder

- `source-records.txt` — the 60 raw records as received
- `data-entry-output.csv` — the cleaned, structured output
- `accuracy-check-log.md` — the second-pass accuracy check and its results

## Verification

An independent second-pass check compared every output cell back against the raw source: **420 of 420 fields (60 records × 7 fields) agree with the source — 0 errors found, 0 corrections needed** (see `accuracy-check-log.md`).

This is a sample built on fictional/practice data to demonstrate the service. Client work is delivered to the same standard.
