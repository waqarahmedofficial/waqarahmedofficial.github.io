# Lead Enrichment — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

A 50-row enriched B2B sample: lead-generation agencies researched from their own public websites and enriched to 13 fields per row — company, website, location, niche, services, size signal, a named decision-maker where one is publicly listed, a public contact email where the agency itself publishes one, an ICP fit score, a buying signal, a personalisation icebreaker written from the company's own site, and the source URLs behind every row. Fields are left blank where no public source exists — nothing is guessed or pattern-constructed. `METHOD.md` describes the enrichment process; `VERIFICATION.md` is the coverage audit of this exact file. The workbook's second sheet (`About This Sample`) explains the sample inside the file itself.

The original sample is an Excel workbook; each sheet is exported here as CSV so it can be viewed directly on GitHub.

## Verification

Per `VERIFICATION.md`: 50 rows × 13 columns; company, website, location, niche, services, buying signal, icebreaker and source complete on 50/50 rows; public contact email on 28/50 (56%) — only where the agency publishes one; named decision-maker on 25/50 (50%); 5 rows spot-checked against the live pages, 5/5 confirmed.
