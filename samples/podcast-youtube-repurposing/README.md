# Podcast & YouTube Content Repurposing — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

One episode — "Do Dogs Understand Fairness? The Treat Test That Split the Pack" from our own EIDOS channel (1,037 words of narration, 406.534 seconds) — turned into a complete written pack: show notes with three title options and short (47-word) and long (192-word) summaries, five YouTube chapters, a six-post X thread with every post inside the 280-character limit, LinkedIn, Instagram/Threads and Facebook posts, six verbatim quotable moments, ten SEO keywords drawn from the episode's own terms, and a 377-word blog/newsletter version. Nothing is invented or padded: every quote is a verbatim substring of the source script, and every number in the pack traces back to the episode itself.

## Files in this folder

- `SHOW-NOTES.md` — title options, summaries, key takeaways and topics
- `YOUTUBE-CHAPTERS.txt` — the five chapters (timestamps labelled as estimates)
- `X-THREAD.txt` — the six-post thread, every post ≤280 characters
- `SOCIAL-POSTS.md` — the LinkedIn, Instagram/Threads and Facebook versions
- `QUOTES.md` — the six verbatim quotable moments
- `SEO-KEYWORDS.txt` — the ten keywords, all attested in the source script
- `BLOG-POST.md` — the 377-word blog/newsletter version
- `SOURCE-MANIFEST.md` — the source record the pack was built and checked against
- `SAMPLE-README.md` — the sample's own README
- `verification_log.txt` — raw verification output
- `REPORT.md` — build report
- `VERIFICATION.md` — the independent recomputation record
