By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

The working sample workbook behind the dashboards service described in `FIVERR-GIG-2.md`. Its structure: a `Data` sheet of raw sales orders; a `Summary` sheet that rolls the data up by product, region and month with SUMIFS/COUNTIFS-style logic; and a `Dashboard` sheet whose KPI band and charts read entirely from those formulas — add rows to the data and every number updates itself. Nothing on the dashboard is a typed-in number.

The original sample is an Excel workbook; each sheet is exported here as CSV so it can be viewed directly on GitHub. Cells that hold live formulas in the workbook are exported as their formula text, so the calculation logic is visible; all other cells show their values.
