# Airtable & Notion Workspace Builds — Work Sample

By Waqar Ahmed — Spreadsheet & Data Specialist (7 years) · Portfolio: https://waqarahmedofficial.github.io

## What this sample shows

A paired workspace build pack covering the same small business in both tools, over one consistent dataset — 8 clients, 12 projects, 30 tasks and 15 invoices, identical field-by-field across both packs. The Airtable side is a complete base: schema, the four table CSVs ready to import, and an import guide. The Notion side is the matching workspace blueprint with a setup guide and three page templates (client onboarding, project kickoff, weekly check-in). Rollups and totals — tasks per project, billed, paid and outstanding — are stored in the pack and were independently recomputed during verification.

## Files in this folder

- `airtable/schema.json` and `airtable/SCHEMA.md` — the base schema (fields, views, formulas)
- `airtable/clients.csv`, `airtable/projects.csv`, `airtable/tasks.csv`, `airtable/invoices.csv` — the four ready-to-import tables
- `airtable/IMPORT-GUIDE.md` — step-by-step import instructions
- `notion/BLUEPRINT.md` — the Notion workspace blueprint (4 databases and relations)
- `notion/SETUP-GUIDE.md` — step-by-step setup instructions
- `notion/templates/client-onboarding.md`, `notion/templates/project-kickoff.md`, `notion/templates/weekly-check-in.md` — the three page templates
- `VERIFICATION.md` — the independent recomputation record
