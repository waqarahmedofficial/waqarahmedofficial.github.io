## What this sample shows

A real business list collected from public Google Maps listings with gosom, the open-source Google Maps scraper (github.com/gosom/google-maps-scraper), using the query "dentist in Austin, Texas". Collection is run in small, paced batches. Each row carries the listing's public fields — business name, category, address, phone, website, review count and rating, opening hours, coordinates and place identifiers — the raw material for B2B lead lists, local-market research and directory building. For client delivery the raw pull is then cleaned, de-duplicated and shaped to the fields the client actually needs.
